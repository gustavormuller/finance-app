## Deviations and decisions

All are recorded with reasons in `docs/DEFERRED.md` (006 · CP1 to CP5). These are the ones that shape later work:

- **Shared tables beyond CLAUDE.md's list.** `MarketAssets` and `SyncRuns` also have no `UserId`.
- **Two ports** (ADR-015 amended), and IVVB11 is a brapi price copied into `Benchmarks`.
- **The stored range ends yesterday (UTC)**, so every stored close is final. CoinGecko's
  00:00 UTC point is dated with its own day. In effect it is the previous day's close.
- **Units are typed** (`BenchmarkUnit`: `PercentPerDay`, `PercentPerMonth`, `Level`) beside
  the SGS codes, not written as comments.
- **The 10-minute limit counts any trigger**, is read from the database, and sits behind an
  in-process gate. A second API instance would need an advisory lock.
- **E2E runs on fakes with no window.** `MarketData:FakeProviders`. The boot is refused
  outside Development.
- **Summary errors are pt-BR, chosen by exception type.** The exception's own message goes
  only to the log.

## Known debts

- The fixtures are hand-written, the SGS codes and the provider behaviours are unverified,
  and there are no keys. See Status.
- **Container TZ.** The cron runs in the container's zone, which is UTC in a stock image.
- **A `Running` row can outlive a killed process.** The screen then polls it, and the
  manual trigger waits out its 10 minutes.
- **Nothing deactivates or deletes a catalogue entry.** Any signed-in user can register
  one, and a typo is shared by everyone.
- **CoinGecko and brapi plan limits** cap the backfill below 5 years on free plans.
- **`InvalidOperationException` reads as "sem configuração"** in a summary even when EF Core raised it.
- Carried from 005: the transactions and categories pages still show English 400 titles;
  five C# files with non-ASCII comments still lack a BOM (`Domain/IUserOwned.cs`,
  `Domain/Transactions/Category.cs`, `Domain/Transactions/Money.cs`,
  `Infrastructure/AuthenticationSetup.cs`, `Infrastructure/GoogleUserInfo.cs`).

## Lessons

- **A shared rate limit and a kept database interact.** "Only one test syncs" passed
  once and failed on the rerun. The window had to come from the switch that makes E2E
  possible at all.
- **Configuration from `WebApplicationFactory` arrives at `Build()`.** Decide config-driven
  swaps when the service is resolved, not when it is registered.
- **Playwright's `getByLabel` matches substrings.** "Provedor" matched "Símbolo no provedor", so use `exact: true`.
