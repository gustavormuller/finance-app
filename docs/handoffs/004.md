## Conventions

**Endpoints.** One static class per resource with `Map<Resource>Endpoints(this
IEndpointRouteBuilder)`, a `MapGroup("/api/…").RequireAuthorization()`, private `sealed record`
request/response DTOs inside the class, handlers taking `AppDbContext` directly (ADR-016, no
repository) and a `CancellationToken`. Register in `Program.cs`. Mutations need `Origin` =
`App:Origin` (`OriginCheck.cs` middleware, runs before auth); multipart routes add
`.DisableAntiforgery()`. Enums go over the wire as names (`JsonStringEnumConverter`).
Somebody else's id → **404** on a route id, **400 naming the field** on a body id (never 403);
see the remarks in `Problems.cs` and `TransactionEndpoints.ResolveAsync`. Unique-index races are
caught as `DbUpdateException.IsDuplicate()` (SQLSTATE 23505) and turned into 409, never pre-checked.
Heavier logic goes into a scoped class in `Application/` returning a result record with a problem
enum (`ImportCommands` / `ImportCommandProblem`), and the endpoint maps that to HTTP.

**pt-BR problem details.** `api/Endpoints/Problems.cs`: `Validation(field, message)`,
`Validation(params RuleViolation?[])` (all failures at once), `Conflict(reason)` (409, title
"Conflito", reason in `detail`). Messages are written inline in pt-BR at the call site, or come
from a pure rule as `RuleViolation(Field, Message)` (`TransactionRules.cs`), or from constants
(`RowIssues` in `Domain/Import/ParsedRow.cs`). Field names stay English. Any C# file with a pt-BR
literal needs a UTF-8 BOM.

**Tenancy.** Implement `IUserOwned` (`api/Domain/IUserOwned.cs`) and the filter follows: the loop
at the end of `AppDbContext.OnModelCreating` applies `UserId == CurrentUser.Id` to every
`IUserOwned` root type. `ICurrentUser` (`Application/ICurrentUser.cs`, `HttpCurrentUser` in
Infrastructure) is a port; new rows set `UserId = currentUser.Id!.Value` explicitly. Joins go
through `DbSet`s so each side brings its own filter (`TransactionEndpoints` GET). **Raw SQL /
Dapper bypasses the filter** — every such query must carry `"UserId" = @userId` itself.

**Tests.** xUnit v3 on Microsoft.Testing.Platform; `api.tests/Unit` (no DB) and
`api.tests/Integration` (Testcontainers Postgres). Classes `<Subject>Tests`, methods are
underscore sentences (`Same_merchant_on_different_days_is_one_key`), and each carries
`/// <summary>Spec unit|integration test N.</summary>`. Integration classes are
`[Collection(nameof(PostgresCollection))]` with a primary-constructor `PostgresFixture`; each test
does `await using var factory = new IdentityApiFactory(postgres.ConnectionString)` and uses
`TestContext.Current.CancellationToken`. Helpers:
- `IdentityApiFactory.cs`: `CreateSignedInClientAsync`, `AuthRequests.DevLogin`, `AppOrigin`
- `TransactionsFixtures.cs`: `SignInNewUserAsync(prefix)` → `SignedInUser(Client, Id)`,
  `ContextFor(connectionString, userId)` (a context filtered as that user), `AnAccount`,
  `ACategory`, `CreateAccountAsync`, `ProblemFieldsAsync`
- `ImportFixtures.cs`: `Ofx(rows)` builder, `Upload(...)` multipart with Origin, `CommitAsync`,
  `GetBatchAsync`, `ListTransactionsAsync`, `CategoriesAsync`; response shapes declared here
  independently of the endpoints, so drift fails a test
- Isolation tests always also show the owner succeeding, so a missing route cannot pass on 404
Web: Vitest + Testing Library, `it('sentence')` with `/** Spec web unit test N. */`, co-located
`*.test.tsx`. E2E: Playwright in `web/e2e/`, `support.ts` has `devLogin(page, email, name)`,
`uniqueEmail(prefix)` (dev DB persists across runs), `createAccount(page, name)`; fixture files in
`web/e2e/fixtures/`. Never modify `e2e/smoke.spec.ts`.

**labels.ts.** `web/src/lib/labels.ts` maps every wire enum to pt-BR with

## Decisions the next spec must make

1. **Transfers (004's known forward dependency).** Importing two accounts double-counts transfers
   between them (card bill paid from checking counts as expense in both). 005 resolves it with
   `CategoryKind.Transfer = 2`. Everything that assumes two kinds must change:
   - `TransactionRules.ValidateSign` already returns null for an unknown kind, so Transfer passes
     rule 3 as-is; tests must pin that and zero still fails via `ValidateAmount`.
   - `CategorySuggester` derives kind from the sign and **rejects any history hit whose kind
     differs** — so a remembered Transfer would be discarded today. 005 says rung 2 may return a
     Transfer; the suggester (and test 34's premise) must change, while defaults never pick one.
   - `DefaultCategories.All` has 8 entries (2 Income, 6 Expense); seeding happens only in
     `ExternalSignIn.cs` inside the user-creation transaction. Adding `Transferência` affects new
     users only; `DefaultCategoriesTests.cs` compares the seeded rows with `DefaultCategories.All`.
   - Web: `CategoryKind` type in `api/finance.ts`; `labels.ts` records; `TransactionForm.tsx`
     derives the sign from the kind (`Expense` → negative, else positive), so a Transfer needs a
     direction input; `CategoriesPage.tsx` offers only Income/Expense; `PreviewStep.tsx:192`
     filters categories by `amount < 0 ? 'Expense' : 'Income'`.
   - `CategoryEndpoints.cs:185` requires a child's kind to equal its parent's.
2. **Aggregation reads.** ARCHITECTURE §6 allows Dapper for dashboard `GROUP BY`s. **Dapper is not
   referenced** in `api/Api.csproj` today (only CsvHelper, Identity, Npgsql EF). Adding it is a
   new package and the first code that bypasses the query filter.
3. **Balances.** `Account` has no opening balance; a balance today can only be the sum of its
   transactions. Any new column needs a migration and a default for existing rows.
4. **The home page.** `/` is `HomePage.tsx` (shortcuts + logout button). Decide whether the
   dashboard replaces it at `/` and where logout moves.

## Known debts

- **No backfill** of `NormalizedDescription` / `ExternalId` on rows entered before 004 or by hand;
  they never match dedupe or history. Pinned by a test at `ImportEndpointTests.cs` (~line 517).
- `ImportCommands.CommitAsync` drops a colliding `ExternalId` when the user includes a duplicate;
  that row can never again be matched by FITID.
- Two implementations of CSV row interpretation: `Domain/Import/CsvMapping.cs` and
  `web/src/lib/csvPreview.ts`. They must be kept in step by hand.
- 003 pages (`AccountsPage`, `CategoriesPage`, `TransactionsPage`) render `ApiError.message`,
  which is `detail ?? title`. A 400 `ValidationProblem` has no `detail`, so the default English
  title would show there; only `ImportPage.tsx` (`describe`, ~line 41) joins field messages.
  Observed in code, not reproduced in a browser.
- `EmptyState` copy is hard-wired to transactions; reuse on another list needs props for the text.
- `CategoryEndpoints` does not check `Enum.IsDefined` on `Kind`; `JsonStringEnumConverter` accepts
  integers by default, so an undefined numeric kind can currently be stored.
- 17 C# files contain non-ASCII (comments only, no literals) without a UTF-8 BOM, e.g.
  `api/Program.cs`, `api/Domain/Transactions/Money.cs`, `Category.cs`, `api.tests/Integration/
  TransactionsFixtures.cs`. Harmless today; a pt-BR literal added to one of them will mojibake.
- Diff-size rule: most 004 commits exceeded ~200 lines (the migration alone 1 095; endpoint tests
  830). The spec warned of it; checkpoints kept each commit single-purpose instead.
- Manual steps 1–8 not yet run (see Status).

## Lessons

From the `fix:` commits and the commit bodies:

- **React Query retries 404s.** Discard/undo refetched a batch the API had just deleted, and the
  default retry-with-backoff left the page busy for seconds (db655ef). Change UI state first so
  the query disables, and set `retry: false` on queries whose resource can legitimately vanish
  (`ImportPage.tsx` ~line 73). Scope Playwright locators to a container when two parts of a page
  offer the same verb.
- **Controlled checkboxes need optimistic updates.** Ticking only after the PATCH round trip reads
  as broken (d275258); update the query cache on `onMutate` and refetch on settle.
- **Real exports break assumptions tests did not.** Bradesco ends every line with `;`, which
  invented a seventh column (cbc91a4); Inter puts four preamble lines above its header; files come
  in Windows-1252. Test against `samples/statements/`, not only hand-made fixtures.
- **Tests before migration surface `PendingModelChangesWarning`** at host startup — expected
  between the mapping commit and the migration commit (39994ef), not a bug.
- **`DateOnly` and `Date` in JS.** `new Date('2026-09-13')` is UTC midnight and renders as the
  12th west of Greenwich; format ISO days by splitting (`formatDate` in `labels.ts`). The UI keeps
  amounts as canonical decimal strings in `csvPreview.ts`, never floats.
- **Round before comparing keys.** `DuplicateMatcher` rounds file amounts to 2 places so they
  equal values read back from `numeric(18,2)` (adb7eee).
- **Let the index decide races.** The one-open-batch rule is a partial unique index; on 23505 the
  open batch id is looked up and returned in the 409 (fe7d1c1).
